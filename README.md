# CodeAlpha_FitnessTracker

## 📚 Description
A simple fitness tracker app that helps users log their workouts, set fitness goals, and track progress over time.

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript (with localStorage for persistence)

## 🚀 Features
- Set fitness goals (exercise type and duration)
- Log workouts (exercise type, duration, and calories burned)
- View total workouts and calories burned
- Track progress toward your fitness goal

## 💻 How to Use
1. Clone the repository
2. Open `index.html` in your browser
3. Set a fitness goal, log your workouts, and track progress!
